効果音の試聴用(ゲーム内ではWebAudioで合成しているので、ファイルは不要)
ok/go/roll/bad/big : 決定・出発・ダイス・失敗・大成功のUI音
hit/crit : 敵に命中 / 大ダメージ   hurt : 被弾   guard : 防御   dodge : 回避(未使用・予備)
heal : 回復   alarm : 戦闘開始   stress : ストレス上昇   corrupt : 侵食上昇   seizure : 発作
door : ダンジョン突入   step : 階層を進む   pop : イベント発生
hullhit : 船体ダメージ   repair : 船体回復   refuel : 燃料補給
coin : 所持金が増えた   buy : 所持金が減った
win / lose / lv / alert / fin : 勝利・敗北・成功・警告・エンディング到達
gameover : ゲームオーバー
