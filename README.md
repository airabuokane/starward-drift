# 星渡りの漂流者 (Starward Drift)

単一HTMLのサイバーパンク・ローグライク。`index.html` を開くと遊べます。

## 遊ぶ
- **GitHub Pages**: リポジトリの Settings → Pages → Branch を `main` / `/ (root)` にすると、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。
- **ローカル**: `file://` で直接開くと、ブラウザの制限で BGM が読み込まれません(ゲーム自体は動きます)。BGM つきで遊ぶには、このフォルダで `python3 -m http.server` を実行し、`http://localhost:8000/` を開いてください。
- 起動すると「TAP TO START」の画面が出ます。タップ(PC なら Enter / スペース)するとタイトル曲が流れ始めます(ブラウザは最初の操作まで音を出せない仕様のため)。

## 主な機能
- **設定**(タイトルの SETTINGS / ゲーム中の上のバー「設定」)
  - BGM・効果音の音量(別々)、音のオン/オフ(次回も記憶)、すりガラス効果のオン/オフ
  - **セーブのバックアップ**: 「書き出す」で文字列化してコピー、または「ファイルに保存」。「貼り付けた文字列を読み込む」「ファイルから読み込む」で復元(上書き前に確認あり)
- **BGM集**(タイトルの MUSIC): 全46曲を名前付きで試聴できます
- セーブはブラウザ(localStorage)に保存されます。ブラウザのデータを消すと消えるので、長く遊ぶ場合は設定画面からバックアップしてください。

## 構成
- `index.html` : ゲーム本体(演出・効果音・BGM の再生コードを含む)
- `pachi.html` : パチンコ店の台の画面(ゲームから全画面で重ねて開く。単体では動かない)
- `bgm/final/` : 基本の曲(タイトル、街、戦闘、ボス、ラスボス、エンディングなど)
- `bgm/extra/` : 星の種類別・ダンジョン別・エンディング別などの曲
- `bgm/README.md` : 曲の割り当て表と、ゲーム内の曲名一覧
- `tools/bgm-generator/` : BGM を生成した Python コード(`pip install numpy scipy pretty_midi pyfluidsynth`、ffmpeg と libfluidsynth、サウンドフォント GeneralUser GS が必要)
- `tools/sfx-preview/` : 効果音の試聴ページ

## BGM・効果音について
- 曲はすべてこのプロジェクトのために作ったオリジナルです(既存曲の旋律は使っていません)。
- 音色は、自作のアナログ風シンセ(コードで合成)と、GeneralUser GS サウンドフォント(S. Christian Collins 作。商用含め自由に使えるライセンス)です。
- 効果音はすべてブラウザ上で合成しています(音声ファイルなし)。
- 真エンディングの曲は、仲間が1人ずつ楽器を持ち寄る本編(09_ending_ab、最後の合奏 123.08〜147.69秒をループ)→ 締め(09_ending_c)の構成で再生します。ラスボス曲は2回目のサビ〜ラスサビ(102.51〜134.51秒)をループし、撃破時は直前のキーに合った締め(11_lastboss_end / _g / _f)を鳴らします。
